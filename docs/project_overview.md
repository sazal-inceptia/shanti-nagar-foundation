### Santi Nagar Association — Project Overview

**Santi Nagar Association** একটি **non-profit foundation/organization**। সংগঠনটির মূল উদ্দেশ্য হলো বিভিন্ন **donor/donation** থেকে পাওয়া অর্থ ব্যবহার করে অসহায় মানুষ ও বিভিন্ন সামাজিক প্রতিষ্ঠানে সহায়তা করা।

### 1. Donation Management
* বিভিন্ন donor সংগঠনটিকে অর্থ প্রদান করবেন।
* প্রত্যেক donation-এর বিস্তারিত তথ্য সংরক্ষণ করা হবে।
* Donor-এর তথ্য, donation amount, date এবং donation-এর উদ্দেশ্য/খাত সংরক্ষণ করা যাবে।
* মোট কত টাকা donation এসেছে এবং কোথায় কত টাকা ব্যয় হয়েছে—তার হিসাব রাখা হবে।

### 2. Project / Social Activities Management
সংগঠনটি বিভিন্ন ধরনের সামাজিক ও মানবিক কাজ করবে। যেমন:
* হাসপাতালের জন্য fan বা প্রয়োজনীয় equipment কিনে দেওয়া
* এতিমখানায় অর্থ প্রদান
* অসহায় মানুষকে আর্থিক সহায়তা
* বিভিন্ন সামাজিক প্রতিষ্ঠানে প্রয়োজনীয় জিনিসপত্র প্রদান
* অন্যান্য charitable/social projects

প্রতিটি project-এর জন্য:
* Project name
* Project description
* Project cost
* Project date
* Project status
* Project-related images
* Donation/fund source
* Project-এর বিস্তারিত activity
সংরক্ষণ করা হবে।

### 3. Donation & Expense হিসাব
Backend dashboard থেকে সংগঠনের পুরো financial activity পরিচালনা করা হবে।
যেমন:
* Total Donation
* Total Expense
* Project-wise Expense
* Donation-wise হিসাব
* Remaining Balance
* অন্যান্য খরচ
* Employee Salary
* অন্যান্য operational expenses
এর মাধ্যমে organization-এর **income এবং expense-এর complete হিসাব** রাখা যাবে।

### 4. Employee / Staff Salary Management
যারা সংগঠনের হয়ে কাজ করবেন, তাদের তথ্যও backend-এ থাকবে।
প্রতিটি employee-এর জন্য:
* Employee information
* Designation
* Joining date
* Salary
* Monthly salary payment
* Salary payment history
* অন্যান্য প্রয়োজনীয় তথ্য
রাখা যাবে।

### 5. Project Documentation & Images
প্রতিটি completed project-এর ছবি এবং documentation সংরক্ষণ করা হবে।
উদাহরণ:
**Project:** Hospital Fan Donation
**Description:** একটি হাসপাতালে প্রয়োজনীয় fan প্রদান করা হয়েছে।
**Cost:** ৳XX,XXX
**Date:** XX/XX/XXXX
**Images:** Project-এর ছবি
**Funding Source:** Donor contribution
এগুলো website-এর মাধ্যমে public-এর কাছেও প্রদর্শন করা যেতে পারে।

### 6. Backend Dashboard
Admin/authorized users-এর জন্য একটি dashboard থাকবে, যেখানে তারা পুরো organization পরিচালনা করতে পারবেন।
**Dashboard-এর সম্ভাব্য modules:**
* Dashboard / Overview
* Donor Management
* Donation Management
* Project Management
* Project Photos / Gallery
* Expense Management
* Employee Management
* Salary Management
* Financial Reports
* User/Admin Management
* Settings

### Overall System Flow
**Donor → Donation → Organization Fund → Project / Assistance → Expense → Documentation → Report**
অর্থাৎ, একজন donor কত টাকা দিয়েছেন → সেই টাকা কোন project-এর জন্য ব্যবহার হয়েছে → project-এ কত খরচ হয়েছে → project-এর ছবি/ডকুমেন্টেশন → সবশেষে financial report—পুরো flow-টি system-এর মাধ্যমে track করা যাবে।

**মূল লক্ষ্য:** একটি centralized system তৈরি করা, যেখানে Santi Nagar Association-এর **donation, social projects, expenses, employee salaries এবং overall financial activities** সুন্দরভাবে সংরক্ষণ ও পরিচালনা করা যাবে।
